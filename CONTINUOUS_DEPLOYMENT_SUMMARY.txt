## 🔄 HOW IT WORKS

### Continuous Monitoring Loop

```
┌─ Every 10 minutes (600 seconds, configurable) ─────────────┐
│                                                              │
│  1. FETCH → Check 45+ federal/intelligence sources          │
│     └─ Parallel HTTP requests (4 concurrent)               │
│                                                              │
│  2. SEARCH → Look for 60+ identifiers & 200+ terms         │
│     └─ Match across all documents & text                   │
│                                                              │
│  3. DETECT CHANGES → Compare with previous cycle           │
│     └─ New entities? New documents? New relationships?      │
│                                                              │
│  4. ALERT → Report findings based on severity              │
│     ├─ CRITICAL: Monica Witt, espionage, indictments       │
│     ├─ WARNING: IRGC, intelligence, documents              │
│     └─ INFO: Government, agencies, federal                 │
│                                                              │
│  5. PERSIST → Save state & log findings                    │
│     ├─ Session state (JSON)                                │
│     ├─ Crawler log (crawler_24_7.log)                      │
│     └─ Alert history                                       │
│                                                              │
│  6. SLEEP → Wait 10 minutes, then repeat                   │
│     └─ Graceful shutdown handling                          │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### Change Detection Algorithm

```
Cycle N-1: [Monica Witt, IRGC] → documents [1,2] → hash ABC123
Cycle N:   [Monica Witt, IRGC, Quds Force] → documents [1,2,3] → hash DEF456

Detected:
  ✓ New entity: "Quds Force"
  ✓ New document: #3
  → Alert Level: WARNING
  → Log & notify
```
