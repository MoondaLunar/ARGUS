  🚀 QUICK COMMANDS

  # Download new model (Recommended)
  ollama pull dolphin-mixtral:8x7b

  # Download alternatives
  ollama pull dolphin-mistral:latest
  ollama pull mistral:latest
  ollama pull llama2-uncensored:latest

  # List installed models
  ollama list

  # Run a model interactively
  ollama run dolphin-mixtral:8x7b

  # Stop Ollama service
  ollama stop

  # Start Ollama service
  ollama serve

  🐍 PYTHON CRAWLER COMMANDS

  # Test setup
  python verify_setup.py

  # Run all examples
  python examples.py

  # Simple crawl
  python -c "
from trawler_enhanced import EnhancedMemoryWebTrawler
trawler = EnhancedMemoryWebTrawler(
    seed_url='https://example.com',
    entities=['ENTITY_A', 'ENTITY_B']
)
result = trawler.crawl()
print(f'Found {len(result[\"links\"])} links')
"

  # Extract image metadata
  python -c "
from metadata_extractor import MetadataExtractor
meta = MetadataExtractor.extract_image_metadata('photo.jpg')
print(meta)
"

  # Fuzzy match entities
  python -c "
from analysis_engine import FuzzyMatcher
matches = FuzzyMatcher.find_similar_entities('John Smith', ['Jon Smyth', 'Jane Doe'])
print(matches)

═══════════════════════════════════════════════════════════════════════════

  📊 REST API COMMANDS (when Java backend is running)

  # Test API is running
  curl http://localhost:8080/api/analytics/summary

  # Create a link
  curl -X POST http://localhost:8080/api/links \
    -H "Content-Type: application/json" \
    -d "{\"entityA\":\"PERSON_A\",\"entityB\":\"PERSON_B\",\"confidence\":0.85,\"sourceUrl\":\"http://example.com\"}"

  # Get entity connections
  curl http://localhost:8080/api/links/entity/PERSON_A

  # Get high-confidence links
  curl http://localhost:8080/api/links/confidence/0.7

  # Store document
  curl -X POST http://localhost:8080/api/documents \
    -H "Content-Type: application/json" \
    -d "{\"sourceType\":\"web\",\"identifier\":\"test-doc\",\"documentType\":\"image\"}"

  # Get all images
  curl http://localhost:8080/api/documents/images

  🎯 COMMON WORKFLOWS

  Scenario 1: First-time setup
  ─────────────────────────────────────────────────────────────────────
  1. pip install -r requirements.txt
  2. ollama pull dolphin-mixtral:8x7b
  3. python verify_setup.py
  4. python examples.py

  Scenario 2: Run a quick crawl
  ─────────────────────────────────────────────────────────────────────
  1. (Edit crawler.py with your URL/entities)
  2. python crawler.py
  3. (Wait 5-10 minutes)
  4. (Results in output.json)

  Scenario 3: Troubleshoot model issues
  ─────────────────────────────────────────────────────────────────────
  1. ollama list
  2. curl http://127.0.0.1:11434/api/tags
  3. ollama pull dolphin-mixtral:8x7b
  4. python verify_setup.py

  Scenario 4: Deploy Java backend
  ─────────────────────────────────────────────────────────────────────
  1. mvn clean install
  2. mvn spring-boot:run
  3. (Wait for "Started" message)
  4. curl http://localhost:8080/api/analytics/summary
